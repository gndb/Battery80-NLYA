# 便携部署与首次免导入

0.2.1使用PyInstaller onedir运行包，内置Python/Tk及依赖，使用Windows自带PowerShell5.1。完整ZIP解压后无需安装额外运行时。默认启动不触及电池、端口或驱动。

第一次确认目录时写本目录deployment.json，记录用户明确批准的绝对根目录与临时签名驱动同意。每次真实启动核对版本、批准根目录及目录链接。只把当前目录当作候选路径，不自动批准。已绑定目录搬动后拒绝启动；不自动删除日志或重绑。

用户批准将“磁盘EC候选副本SHA校验”替换为“内置分析记录固定SHA校验”。assets/verified-policy.json包含候选哈希、确认身份、固定命令及有界存储审计结论，无固件字节。它只校验发布材料完整性，不能校验运行EC全镜像；旧候选文件检查同样不证明运行EC完整镜像一致。

仍要求THUNDEROBOT/NLYA/TP181、IT5570 rev07与两次C009A0运行标识；驱动SHA固定，Authenticode必须Valid且发行者匹配；签名检查失败或系统禁止驱动时停止，不关闭安全功能。不重新编译或修改驱动。

真实启动需管理员权限，创建需求启动的临时内核驱动登记Battery80InpoutProbe。退出后停止、删除并验证服务/设备映射清理；这是明确允许的系统变更，非“完全不写系统”。不创建开机启动、任务或持久服务。故障日志在evidence/panel。

应用程序exe未做代码签名；第三方驱动有原签名，不能把驱动签名当exe签名。其他电脑或安全配置仍需独立验证，本次制作不加载驱动。
