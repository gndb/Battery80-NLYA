# 运行与恢复

1. 下载运行ZIP，完整解压到普通可写目录；不要放在系统目录、目录连接或符号链接中。
2. 双击BatteryPanel.exe。首次免ROM导入；勾选部署和临时签名驱动确认，点击“打开真实面板”，接受UAC。以后仍手动点击打开。
3. 面板先读真实状态，查看电量、EC目标、供电/充放电与功率；不能把“开启成功”仅看作按钮状态。
4. 点击开启80%；高于目标时需要确认可能主动放电。目标固定80%，没有任意寄存器或任意阈值。
5. 成功开启后关闭窗口不取消，EC继续执行，监督进程清理临时驱动。
6. 恢复：重新打开同一部署目录的exe，点击“取消维护”，确认实际参数回读为停用的默认状态。默认目标60是停用编码，不是60%限充。

不要删除session/driver日志来绕过故障锁。协议不确定时程序拒绝重复写入；联系维护者审查日志。Windows崩溃/强杀监督进程可能留下驱动登记，不能保证自动清理或自动恢复。不要通过重启/断电臆测恢复。

移动目录前退出全部进程并保留全部日志；绑定目录不匹配会拒绝控制，不自动重绑。直接使用新ZIP建立新部署前也需审查旧故障记录，不能用新文件夹绕过未解决的硬件状态。

命令行：`BatteryPanel.exe --preview`为模拟外观；`--preview-smoke`短时模拟退出；`--self-test`只做文件校验和独立子进程检查，日志写本目录evidence/packaging；它不测试真实驱动签名、EC或充电。
