# 0.2.1 发布内容

源码包：便携入口、适配模块、模拟测试、中英文与研究文档、分析记录、原签名驱动和许可、构建脚本与锁定依赖。运行包：exe、_internal依赖、驱动、许可、使用与恢复文档。无ROM/EC字节、OEM安装器、原系统/会话日志、私人路径、凭据或Git历史。

原项目生产文件保留原位。发布副本变更仅为路径部署绑定、内置分析记录、Windows自带PowerShell与冻结exe子进程启动；原协议、控制/恢复与驱动生命周期逻辑未改变。

用户已批准首次免导入。不能把替换后的分析记录称作实机固件全哈希校验。源模块里保留的历史trial/query入口不是发布操作入口，只用portable_entry.py或运行exe。

本次不上传GitHub；运行ZIP作为Release附件，源码ZIP解压后的目录内容作为仓库。原创开源许可证仍待版权人指定，保留许可状态说明。InpOut、Python/Tk、PyInstaller按各自许可附带原通知。

本版更新黑金显示模块与版本绑定，重新构建exe；协议和控制/恢复逻辑不变。旧版本文档中的同exe哈希结论只适用于r2，不适用于本版。
