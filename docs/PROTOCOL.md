# NLYA固定80%协议证据摘要

此页记录特定固件组合的逆向结果，不是ITE通用接口，不作为他机写入说明。参数均为十六进制。

| 操作 | PMC2命令与参数 | 验证依据 |
|---|---|---|
| 固定字段查询 | 6C写92，68依次地址高、低字节，返回一个字节 | ROM候选分发和固定白名单读回 |
| 原厂80%设置 | 6C写73，68写50 | 三次0475=D0及操作完成记录 |
| 取消维护 | 6C写74，无目标参数 | 三次默认状态、分支/ Learn清除及独立恢复查询 |

实际实现先检查IBF/OBF、残留输出和预算，等待最长1秒；不能直接把表格翻译成无握手的端口脚本。固定查询字段与动态判据以源码为准。

| 运行期字段 | 本机解释 |
|---|---|
| 0475 | bit7为启用，低7位目标；D0为启用80；3C为停用/默认参数60，不是开启60%限充 |
| 0476高位 | 10低于目标、20高于目标/Learn、40相等/零电流、80门控候选分支 |
| 0396 | EC SOC，用于和Windows SOC交叉核对 |
| 03A6.bit1 | Learn请求 |
| 0340.bit3 / bit0 | 适配器检测ADPP / Windows供电来源相关SW2S，不能互相替代 |

取消除目标/分支/ Learn外，还触及0442、03A5.bit5、0382.bit0及0450..0453等运行期状态。不能把取消理解为仅翻转一个开关。

有界离线审计覆盖已解析的73设置及参数、74取消handler：未发现BIOS/EC Flash或UEFI写入器调用。它不是全固件非易失存储审计。运行EC全镜像哈希未验证，候选哈希与运行构建标识是分开的证据。

ROM与候选仅公开哈希和摘要，原字节不包含。读者无法仅靠此发布包复算完整CFG；复算需要合法获得同机型固件并验证 [SOURCES.json](SOURCES.json) 中的哈希，不绕过控制门控。
