## 尚需实机验收

1. 记录基线、参数及取消恢复；选择自然降低电量，不用未知工具强制放电。
2. 从低于目标的SOC插电充到约80%，连续保持至少30分钟，记录容量、功率、供电状态及控制回读。
3. 允许约±2个百分点显示误差；持续超过范围或容量持续增长算失败。
4. 完成第二次独立充电、取消后的真实充电恢复、适配器重连、正常/异常退出、睡眠唤醒与办公负载供电。
5. 重启与深度掉电保持单独记录；不要从关窗口保持推导。

异常退出/整机崩溃不以模拟测试替代现场恢复能力。实机步骤需明确授权，不能在CI或打包脚本中执行。
