# 故障处理

| 现象 | 处理 |
|---|---|
| 缺少_internal/Tk/DLL | 重新完整解压运行ZIP，不只复制exe |
| 未绑定 | 默认启动页明确确认部署；不要手工伪造deployment.json |
| 移动后目录不匹配 | 保留旧日志、审查是否有未解决故障，重新部署需人工审查 |
| 身份不匹配 | 不支持此机型/版本，不删白名单 |
| 分析记录或驱动哈希不匹配 | 停止使用，重新取得完整可信发布包 |
| 驱动签名检查/加载失败 | 查看错误，保留系统安全配置，不绕过或重签 |
| Windows PowerOnline=false | 高于目标Learn分支可能如此；结合EC适配器位和功率，不据此称用户拔电源 |
| 未解决传输/取消故障 | 停止新查询，保留session/driver日志，不反复开启、取消或删日志 |
| 驱动服务残留 | 保留生命周期记录并交维护者处理，不创建新服务覆盖 |

报告只保留脱敏机型、版本、错误、操作顺序和必要状态，不公开用户路径、序列号、MAC、固件或原日志。运行exe不是通用限充程序，不支持其他版本猜命令。
