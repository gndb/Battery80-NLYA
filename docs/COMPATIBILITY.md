|---|---|
| 商品名（使用者提供） | 雷神猎刃16 / THUNDEROBOT LieRen 16 |
| Windows系统型号 | R16 |
| 平台制造商 / 主板 | THUNDEROBOT / NLYA |
| BIOS | TP181 |
| EC芯片 / 修订 | IT5570 / 07 |
| 运行构建标识 | C009A0 |
| 已验证目标 | 固定80% |
| 数据 / 命令状态端口 | 0x68 / 0x6C |

本机具体测试及脱敏采样见[实测参考型号](TESTED_MODEL.md)。商品名、系统型号和CPU用于识别参考机器，不扩大程序白名单。

原有平台、BIOS、EC修订及运行标识组成控制白名单。营销型号“雷神猎刃16 / R16”不足以匹配，TP181、同模具或同芯片任一项也不能单独匹配。构建字符串一致不等于运行镜像全哈希相同。

原厂策略高于目标会请求Learn放电，等于目标进入零电流候选分支，低于目标允许充电；它不是可配置的75/80双阈值。在其他BIOS/EC版本上需要独立逆向、读回与恢复证据，不要删除现有白名单来试。

程序不刷BIOS或EC、不修改UEFI/NVRAM，不发送未知SMI，不支持未知地址试写、驱动安全策略绕过、适配器切断、强制放电工具或设备禁用。真实使用会临时创建、启动、停止、删除一个内核驱动服务登记；这会触及Windows服务管理，不是“只读取系统文件”。必须有当次用户授权及管理员权限。

演示、开发测试、CI和本次发布验证只用模拟后端，没有这些系统或硬件动作。发布程序只保留手动启动方式。
